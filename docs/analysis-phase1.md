# Phase 1: 発言抽出とAI関連語の頻度分析

対象は `data/raw/shogi_yearbook_{year}_fulltext.txt` の2017・2020・2023・2026年の4ファイル。

## 実行（Python 3.10以降）

```bash
python -m pip install -e ".[dev]"
python -m shogi_analysis --data-dir data/raw --output-dir outputs/tables
python -m pytest
```

出力は `utterances.csv`（原文追跡可能な発言単位）、`frequency_by_year.csv`（年×棋士・質問者別の件数と1万字あたり頻度）、`kwic.csv`（キーワード前後35文字）、`context_review_candidates.csv`（AIに関する質問への語彙上の非該当回答・要人手確認）。生成物はGit追跡対象外。

## 明示的な分析ルール

- 【本文】にある質問者と棋士の発言だけを集計し、見出し・リード・棋譜図・結果欄は除外する。
- `AI`・`ＡＩ`・`人工知能`を同一概念とし、「AI（人工知能）」のような併記は1回と数える。「ソフト」「コンピュータ」は別分類。
- Unicode NFKCは**検索時のみ**適用し、出典の言葉は上書きしない。
- ページをまたぐ発言は一つに結合する。開始・終了の誌面ページ、ソーステキストの行番号を記録する。
- 1万字あたりの頻度の分母は**発言本文の文字数**であり、形態素数ではない。
- 「研究」などの単語だけでAI研究と断定しない。AI質問に続く直接言及のない回答は人手確認候補に出す。
- 2026年は校正・勝敗欄の整合性チェックが必要。分析結果は探索的なもので、原本との照合前に確定しない。
- **各年1記事**で質問内容・回答棋士が異なる。年次差から将棋界全体の傾向や因果効果を断定しない。

次のPhase 2では形態素解析による共起語・特徴語、手動コードブックによる認識変化の分類を追加する。
